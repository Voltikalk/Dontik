# 🚗 Telegram-бот «Пётр» — ежедневный и авто-гаражный ассистент

Персональный помощник на Python: понимает голос и текст, ведёт задачи, считает
расходы и запоминает вещи в гараже, решает математику с нативным рендерингом
формул прямо в чате, ищет в интернете, разбирает файлы и фотографии.

---

## 🛠 Стек

- **Python 3.10+** (проверено на 3.13)
- **aiogram 3.31+** — работа с Telegram Bot API 10.1+ (Rich Messages)
- **SQLAlchemy 2.0 + aiosqlite** — асинхронная ORM, SQLite в режиме WAL
- **Groq API** через OpenAI SDK:
  - `whisper-large-v3-turbo` — транскрибация голоса
  - `openai/gpt-oss-120b` — ответы и разбор намерений (фолбэки: `gpt-oss-20b`, `qwen`)
- **tg-rich-converter + pylatexenc** — Markdown/LaTeX → нативные формулы Telegram

## ✨ Что умеет

### Математика и точные науки
Формулы рендерятся **нативно самим Telegram** внутри одного пузыря сообщения:

```
Скорость v = s/t = 100 м / 20 с = 5 м/с
```
- блочные формулы `$$...$$` → `<tg-math-block>` (центрируются клиентом)
- строчные `$...$` → `<tg-math>` (`$v$`, `$m$`, `$\Delta t$`)
- цены вида `$5`, `$10.99` не ломаются — есть детектор формул
- четырёхуровневый откат: LaTeX → Unicode → обычный HTML → plain text

### Задачи и покупки
- Срок распознаётся и **разбирается в дату**: «завтра», «в субботу», «через 3 дня», «14.10», «1 января», «в 18:30»
- Сортировка: просроченные → по сроку → без срока
- Подсветка просроченных и горящих задач
- Кнопка «✅ Всё выполнено» и «↩️ Вернуть» после закрытия
- Удаление голосом: «удали задачу про грабли»

### Автомобиль
- Заправки с расчётом цены за литр и среднего расхода л/100 км
- Сервис и ремонты с привязкой к пробегу
- Расход считается по нескольким заправкам, мусор в одометре отбрасывается

### Гарраж и дача
- «Положил домкрат под верстак» → карточка с подтверждением
- «Где лежит домкрат?» → умный поиск: понимает склонения (*подшипник* → *подшипников*), регистр и лишние слова
- Каждой карточке можно **исправить любое поле**, не записывая голос заново

### Ассистент и поиск
- Вопросы по автомобилю, ремонту, кухне, здоровью, деньгам, закону
- Веб-поиск (DuckDuckGo) включается только когда нужны свежие данные
- **Команда субагентов** `/agent`: поиск цен, техэксперт, смета, планировщик, критик

### Файлы и фото
- PDF (включая сканы через Vision), Word, Excel, CSV, TXT
- Фотографии: детали, чеки, приборные панели, схемы, маркировки
- В подписи можно сразу задать вопрос

### Ключевые решения

| Решение | Зачем |
|---|---|
| Синглтон `AsyncOpenAI` + ретраи с джиттером | Один httpx-пул, переживание 429/5xx без падений |
| Цепочка моделей `gpt-oss-120b → 20b → qwen` | Ответ не теряется при перегрузке Groq |
| Юникод-`lower()` для SQLite | «Компрессор» и «компрессор» — один предмет |
| Ранжирование поиска в Python | `LIKE` в SQLite не понимает кириллицу |
| Миграции в `migrations.py` | Старая БД доезжает до новой схемы без потери данных |
| Единый `input_handler` | Голос и текст обрабатываются одинаково |
| Токен-бюджет истории | Контекст не раздувает запрос и не обрезается до бесполезного |
| `MemoryStorage` в явном виде | Поведение при рестарте не зависит от версии aiogram |

## 🚀 Запуск

```bash
pip install -r requirements.txt
cp .env.example .env    # Windows: copy .env.example .env
```

Заполни в `.env`:

| Переменная | Описание |
|---|---|
| `BOT_TOKEN` | Токен от [@BotFather](https://t.me/BotFather) |
| `GROQ_API_KEY` | Ключ с [console.groq.com/keys](https://console.groq.com/keys) |
| `ALLOWED_TELEGRAM_IDS` | ID через запятую. Пусто = доступ для всех |

```bash
python main.py
```

При старте бот применяет миграции, регистрирует команды в меню и пишет приветствие
разрешённым пользователям. Без `BOT_TOKEN`/`GROQ_API_KEY` — сразу выходит с ошибкой.

## 💬 Команды

| Команда | Что делает |
|---|---|
| `/start` | Главное меню с кнопками |
| `/tasks` | Задачи с кнопками «выполнено» и «всё выполнено» |
| `/stats` | Последняя заправка, сервис, средний расход |
| `/items` | Каталог вещей |
| `/agent` | Команда субагентов |
| `/mail` | Сводка писем |
| `/clear` | Сброс памяти диалога |
| `/help` | Справка |

Работают и обычные слова: «задачи», «статистика», «гараж», «письма», «помощь», «забудь».
На опечатку в команде бот подскажет похожую. На непонимаемый тип сообщения — объяснит,
что умеет, вместо тишины.
