# 🚗 Telegram-бот «Авто-Гараж Ассистент»

Интеллектуальный ассистент водителя и владельца гаража/дачи на Python с поддержкой голосового ввода через **Groq Whisper** и автоматического структурирования данных через **Groq LLM (Llama 3.3)**.

Позволяет вести учет заправок, журнал сервисного обслуживания и каталог хранения вещей в гараже или на даче с помощью обычных голосовых или текстовых сообщений.

---

## 🛠 Стек технологий

- **Python 3.10+** (протестировано на Python 3.13)
- **aiogram 3.x** — современный асинхронный фреймворк для Telegram Bot API.
- **SQLAlchemy 2.0 + aiosqlite** — асинхронная ORM и база данных SQLite.
- **Groq API (OpenAI SDK)**:
  - `whisper-large-v3` — сверхбыстрая и точная транскрибация голосовых сообщений.
  - `llama-3.3-70b-versatile` — извлечение сущностей, намерений (JSON Mode) и автосоветы.
- **pydantic-settings & python-dotenv** — валидация конфигурации через `.env`.

---

## 📱 Дизайн и UX в Telegram (AI Best Practices)

1. **Индикация процесса (`send_chat_action`)**:
   - При обработке голосовых или текстовых запросов бот отправляет статус `Typing`, информируя водителя о работе нейросети.
2. **Раскрывающиеся блоки (`<blockquote expandable>`)**:
   - Поддерживаются Telegram Bot API 7.2+. Распознанная транскрипция аудио сворачивается в аккуратную цитату, не загромождая экран смартфона.
3. **Human-in-the-loop (Подтверждение перед записью)**:
   - AI не записывает данные вслепую: формируется интерактивная карточка с инлайн-кнопками `[✅ Записать в журнал]` и `[❌ Отмена]`.
4. **Безопасное HTML-экранирование**:
   - Использование `ParseMode.HTML` исключает падения Telegram из-за неэкранированных спецсимволов (`MarkdownV2`).

## 🗄 Структура базы данных (SQLite)

- **User**: пользователи бота (`telegram_id`, `full_name`, `is_admin`, `created_at`).
- **FuelLog**: журнал заправок (`id`, `user_id`, `date`, `liters`, `cost`, `odometer`, `station_name`).
- **ServiceLog**: журнал ТО и ремонтов (`id`, `user_id`, `date`, `odometer`, `title`, `cost`, `notes`).
- **ItemLocation**: инвентарь гаража/дачи (`id`, `user_id`, `item_name`, `location`, `updated_at`).

Файл базы данных автоматически создается по пути: `data/garage.db`.

## 🚀 Быстрый старт

### 1. Клонирование и установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Настройка переменных окружения

Скопируйте шаблон `.env.example` в `.env`:
```bash
cp .env.example .env
```

Заполните переменные в `.env`:
- `BOT_TOKEN` — токен бота из [@BotFather](https://t.me/BotFather).
- `GROQ_API_KEY` — API-ключ от [Groq Console](https://console.groq.com/keys) (доступен бесплатный тариф).
- `ALLOWED_TELEGRAM_IDS` — ID пользователей через запятую (например, `123456789,987654321`). Если оставить пустым — бот будет открыт для всех. Свой ID можно узнать через [@userinfobot](https://t.me/userinfobot).
- `DATABASE_URL` — путь к SQLite базе (по умолчанию `sqlite+aiosqlite:///data/garage.db`).

### 3. Запуск бота

```bash
python main.py
```

При первом запуске автоматически выполнится `init_db()` и создадутся все необходимые таблицы в `data/garage.db`.

## 💬 Примеры использования

### ⛽ Учет заправки (голосом или текстом)
> *«Заправил 42.5 литра на Лукойле на 2500 рублей, одометр 114300»*
- Бот сформирует карточку с расчетом цены за литр и кнопками подтверждения.

### 🔧 Запись ТО и сервиса
> *«Поменял масло в двигателе и масляный фильтр, отдал 6200 рублей, пробег 115000»*
- Запись зафиксируется с привязкой к текущему пробегу.

### 📦 Инвентарь гаража и дачи
> *«Положил съемник подшипников на третью полку стеллажа у верстака»*
- Бот запомнит предмет и местоположение.
> *«Где лежит съемник?»*
- Бот мгновенно найдет и покажет точное место.

### 📊 Статистика
- Нажмите кнопку **«📊 Сводка и расходы»** или напишите *«покажи статистику»*, чтобы увидеть суммарный объем топлива, затраты и среднюю цену за литр.
